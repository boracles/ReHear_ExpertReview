# Re:hear Expert Review

[전문가 검토 사이트](https://boracles.art/ReHear_ExpertReview/)

VR 발표 훈련 환경에서 발표 수행에 따라 반응하는 AI 청중 에이전트의 백채널 디자인 프레임워크를 검토하기 위한 전문가 전용 사이트입니다. 불특정 다수를 대상으로 하는 공개 모집 페이지가 아니라, 관련 분야의 연구·교육·실무 경험을 보유한 전문가에게 개별적으로 전달하는 연구 참여 안내 및 평가 도구입니다.

## 연구 개요

- **연구 과제명:** VR 발표 훈련 환경에서의 발표 수행 평가 기반 AI 청중 에이전트 백채널 디자인 프레임워크
- **연구책임자:** 윤보라 · 서울대학교 디자인학부
- **검토 대상:** 발표·커뮤니케이션, HCI·Human–AI Interaction, XR 인터랙션 또는 가상 에이전트 분야 전문가
- **검토 내용:** 수행정보–백채널 연동 규칙, 발표 맥락, 백채널 애니메이션 예시 및 프레임워크 전체 평가

## 참여 절차

1. 후보 전문가에게 개인별 **모집·안내 링크**를 전달합니다.
2. 안내 페이지에서 연구 목적, 참여 내용, 소요시간, 사례 및 자율성을 확인합니다.
3. 참여 의사가 있는 경우 연구 설명문과 동의서를 제공하고 동의 절차를 진행합니다.
4. 동의가 완료된 전문가에게만 별도의 **평가 링크**를 전달합니다.
5. 독립 평가 후 연구자와 1:1 반구조화 면담을 진행합니다.

모집·안내 링크에서는 평가표를 작성할 수 없습니다. 평가표는 동의 완료 후 전달되는 별도 평가 링크에서만 열립니다.

## 참여자 링크 운영

- 참여자 6명에게 `EXP-01`부터 `EXP-06`까지 익명 ID를 부여합니다.
- 각 참여자에게 모집·안내 링크와 동의 후 평가 링크를 별도로 발급합니다.
- 각 링크에는 256비트 무작위 토큰이 사용됩니다.
- 공개 코드에는 링크 원문이 아니라 SHA-256 해시만 포함됩니다.
- 실제 링크 목록은 로컬의 `private/participant-links.csv`에 보관되며 Git에는 포함되지 않습니다.
- 참여 의사 문자 초안과 평가 결과 파일에는 해당 참여자의 익명 ID가 포함됩니다.

## 접근 및 데이터 처리

현재 사이트는 GitHub Pages에서 운영되는 정적 사이트입니다. 로그인이나 이메일 인증 기능은 아직 적용되어 있지 않으며, 개인별 링크를 알고 있는 경우에만 접근하는 방식입니다. 링크를 전달받은 사람이 다시 공유하면 다른 사람도 열 수 있으므로 링크를 외부에 공개하지 않아야 합니다.

평가표 입력 내용은 서버로 전송되지 않고 참여자의 브라우저에만 임시 저장됩니다. 작성 완료 후 참여자가 JSON과 CSV 파일을 내려받아 연구자에게 전달하는 방식입니다. 이메일 인증이나 자동 응답 수집이 필요한 경우 별도의 인증 및 서버 저장소가 필요합니다.
