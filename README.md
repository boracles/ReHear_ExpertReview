# ReHear Expert Review

VR 발표 훈련 환경에서의 AI 청중 에이전트 백채널 디자인 프레임워크 전문가 검토 초대 사이트입니다.

## 참여자 링크 운영

- 참여자 6명에게 `EXP-01`부터 `EXP-06`까지 익명 ID를 부여합니다.
- 각 참여자는 서로 다른 256비트 무작위 초대 링크를 받습니다.
- 공개 코드에는 링크 원문이 아니라 SHA-256 해시만 포함됩니다.
- 실제 초대 링크 목록은 `private/participant-links.csv`에 있으며 Git에 포함되지 않습니다.
- 참여 의사 문자 초안에는 해당 참여자의 ID가 자동으로 붙습니다.

> GitHub Pages는 로그인 기반 인증 서비스가 아닙니다. 이 방식은 링크를 추측하기 어렵게 만드는 개별 초대 방식이며, 링크를 전달받은 사람이 다시 공유하면 다른 사람도 열 수 있습니다. 민감한 연구 응답을 웹에서 직접 수집하려면 별도 인증과 서버 저장소가 필요합니다.

## 게시

`main` 브랜치에 변경 사항을 올리면 GitHub Actions가 정적 사이트를 빌드해 GitHub Pages에 자동 게시합니다. 검색엔진에는 노출되지 않도록 `noindex`와 `robots.txt`를 적용했습니다.
